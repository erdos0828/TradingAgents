# 持仓分析汇总页面说明

`持仓分析汇总` 是 `python -m cli.main serve` 启动后默认打开的 Web 页面。它读取本地 `data/portfolio_holdings.json` 持仓文件、`reports/` 目录下的多智能体分析报告，以及 `cache/` 里的 OHLCV 行情数据，动态生成一份可视化的持仓日报。

---

## 视觉风格

当前版本采用 **浅色专业仪表板（Light Professional Dashboard）** 风格：

- **浅灰底 + 蓝色强调**：以浅灰 (#f6f7f9) 为底，白色卡片浮于其上，蓝色 (#2563eb) 作为交互与强调色。
- **字体组合**：全站使用 *Inter*，数据指标使用等宽字体 *JetBrains Mono*，保持清晰易读。
- **卡片式布局**：持仓卡片与汇总面板使用白色背景、浅灰边框与柔和投影，悬停时有轻微抬升效果。
- **K 线图浅色主题**：图表背景为白色，网格线淡灰，红涨绿跌，成本线以琥珀色虚线标注。
- **动效**：页面加载时卡片依次淡入上浮，标签页切换带有平滑过渡，悬停状态有细腻的抬升与边框高亮。

---

## 启动方式

```bash
python -m cli.main serve
# 指定端口/路径
python -m cli.main serve --port 8080 --holdings data/portfolio_holdings.json
```

启动后访问控制台打印的地址（默认 `http://127.0.0.1:5000`）。

底层实际是调用 `scripts/portfolio_summary_server.py`。

---

## 数据来源

| 来源 | 默认路径 | 说明 |
|------|---------|------|
| 持仓配置 | `data/portfolio_holdings.json` | 股票代码、名称、持股数量、成本价 |
| 分析报告 | `reports/{ticker}/{YYYY-MM-DD}_{HHMMSS}/` | TradingAgents 生成的完整报告 |
| 行情缓存 | `cache/{ticker}-YFin-data-*.csv` | OHLCV 日 K 数据 |
| 交易记录 | `data/transactions/transactions.json` | 用于在 K 线图上标注买卖点位 |

## 页面功能区

### 1. 顶部控制栏

- **选择日期**：下拉框列出 `reports/` 目录中实际存在报告的所有日期。选择日期后点击「生成报告」即可回退查看历史某一天的汇总。
- **生成报告**：按所选日期重新扫描报告并渲染页面。
- 若所选日期没有报告，系统会自动回退到最近一个有数据的日期。

### 2. 市场分区标签页

页面按市场自动把持仓分成两类：

- **A股**：后缀为 `.SS` / `.SZ` 的标的。
- **美股**：其余标的。

标签页显示每个分区的持仓数量，例如 `A股 (3)`、`美股 (7)`。点击标签切换显示对应分区。

### 3. 分区总体概览

每个分区顶部是一个 `region-dashboard`  executives 面板，左侧为 6 项核心 KPI，右侧为近一周信号热力图。

#### 3.1 分区 KPI 网格

| 指标 | 说明 |
|------|------|
| 证券市值 | 按最新收盘价 × 持股数加总 |
| 持仓成本 | 按成本价 × 持股数加总 |
| 今日盈亏 | 相对前一交易日收盘价的盈亏金额及百分比 |
| 累计盈亏 | 相对成本价的累计盈亏金额及百分比 |
| 持仓数量 | 该分区下的标的数量 |
| 组合权重 | 该分区持仓成本占全仓成本的比例 |

颜色采用 A 股习惯：**红色表示上涨/盈利，绿色表示下跌/亏损**。

#### 3.2 近30天信号热力图

`近30天信号` 矩阵位于 KPI 网格右侧：

- 每行代表一只持仓标的，**左侧显示股票名称**（A股）或 ticker 代码（美股）。
- 每列代表一个交易日（共 30 天），日期按从新到旧倒序排列（31、30、29…）。
- 每周之间会有一条细竖线作为周分隔，便于快速定位周界。
- 色块为紧凑的小方块（16×16px），不同评级使用不同颜色：
  - 深红色块：当天评级为 `Buy`（买入）
  - 浅红色块：当天评级为 `Overweight`（增持）
  - 深绿色块：当天评级为 `Sell`（卖出）
  - 浅绿色块：当天评级为 `Underweight`（减持）
  - 黄色块：当天评级为 `Hold`（持有）
  - 浅灰色块：当天无报告或评级缺失
- 鼠标悬停会显示深色提示条，包含具体日期、标的名称和评级。

### 5. 个股持仓卡片

分区明细以 2 列网格展示（窄屏自动降级为 1 列）。每只标的对应一张 `holding-card` 玻璃卡片，结构如下：

#### 5.1 卡片头部

- **名称 + 代码**：如 `东风股份 600006.SS`。
- **最新评级**：当前所选日期报告中的 Portfolio Manager 评级标签（如 `OVERWEIGHT`、`UNDERWEIGHT`、`HOLD`）。
- **Report →**：点击后跳转到 `/reports` 报告浏览器，并自动定位到该标的、该日期的详细报告。

#### 5.2 核心指标网格

卡片主体以 2×2 网格展示 4 组关键数据：

| 指标 | 说明 |
|------|------|
| 市值 / 数量 | 当前市值 与 持股数量 |
| 现价 / 成本 | 最新收盘价 与 成本价 |
| 当日盈亏 | 相对前一日收盘的盈亏金额和百分比 |
| 持仓盈亏 | 相对成本价的累计盈亏金额和百分比 |

#### 5.3 历史评级标签

紧跟指标网格下方，展示最近 3 天（可配置）的评级历史，格式为 `日期: 评级`。

#### 5.4 可折叠详情：投资建议 & 走势

点击卡片底部的「投资建议 & 走势」可展开：

- **投资建议**：Portfolio Manager 报告中的 `Executive Summary` 与 `Investment Thesis`。
- **历史走势**：基于 `lightweight-charts` 绘制的 K 线图，默认高度 320px，白色背景，展示最近约两个月数据。
  - 红色 K 线表示上涨，绿色 K 线表示下跌。
  - **B / S 标记**：如果有交易记录，买入点显示红色向上箭头 `B`，卖出点显示绿色向下箭头 `S`。
  - **成本线**：以琥珀色虚线标注平均成本价（当持仓配置中存在有效成本价时）。
  - **鼠标悬停**：显示当日 OHLC（开高低收）以及该日的买卖汇总信息（数量、均价）。

## 集成的报告浏览器

同一服务还提供了独立的报告浏览页面：

```
http://127.0.0.1:5000/reports
```

功能：

- 左侧选择 `ticker`，右侧列出该标的的所有报告日期。
- 点击日期后，顶部出现报告分节标签：`核心报告`、`分析师`、`研究团队`、`交易团队`、`风险管理`、`投资组合`。
- 内容区以 Markdown 渲染方式展示完整报告，可直接阅读多智能体分析结果。
- 从持仓汇总页面点击「查看详细报告」会自动携带 `#ticker=...&date=...` hash 参数打开并定位。

## 常用配置项

可通过环境变量或命令行参数覆盖：

| 环境变量 | 命令行参数 | 默认值 | 说明 |
|----------|-----------|--------|------|
| `PORTFOLIO_HOLDINGS` | `--holdings` | `data/portfolio_holdings.json` | 持仓文件 |
| `PORTFOLIO_REPORTS_DIR` | `--reports-dir` | `reports` | 报告根目录 |
| `PORTFOLIO_CACHE_DIR` | `--cache-dir` | `cache` | 行情缓存目录 |
| `PORTFOLIO_TRANSACTIONS` | - | `data/transactions/transactions.json` | 交易记录 |
| `PORTFOLIO_REPORT_SERVER_URL` | `--report-server-url` | `/reports` | 详细报告链接基地址 |
| `PORTFOLIO_PAST_DAYS` | - | `3` | 历史评级标签展示天数 |
| - | `--host` / `--port` | `127.0.0.1:5000` | 监听地址 |

## 注意事项

1. **日期回退逻辑**：如果选择的日期没有报告，页面会自动选择该日期之前最近一个有报告的日期。
2. **评级来源**："最新评级" 仅在报告日期等于所选日期时显示；否则显示 `N/A`。历史标签则展示目标日期之前的最近 N 天评级。
3. **价格依赖**：若某只标的在 `cache/` 中没有可用收盘价，该标的不显示，并在空状态区列出错误信息。
4. **响应式适配**：分区 KPI 网格在窄屏下由 3 列变为 2 列或 1 列；持仓卡片由 2 列变为 1 列；历史评级标签在小屏幕下会隐藏。
